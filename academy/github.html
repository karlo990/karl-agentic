Beginner GitHub in 5 min

GitHub stores your code online and keeps a history of every change. This whole website lives in a GitHub repo.

PART 16 LESSONSFROM OUR INSTAGRAM SERIES

Repository

01 · THE PROJECT FOLDER

A repo holds all your project's files and their full history. Create one at github.com/new.

TRY THISCreate a repo called my-first-site with a README.
Learn more ↗

Commit

02 · A SAVED SNAPSHOT

A commit saves your changes with a short message explaining why. Small, frequent commits are easier to undo.

TRY THIS
git add .
git commit -m "Add pricing section"
git push
Learn more ↗

Branch

03 · A SAFE COPY

Try new ideas on a branch without breaking the live site. main is usually the live version.

TRY THIS
git checkout -b new-homepage
Learn more ↗

Pull request

04 · REVIEW BEFORE MERGING

A pull request asks to merge a branch into main. Teammates (or AI reviewers) can comment first.

TRY THISOpen a pull request from new-homepage into main and read the 'Files changed' tab.
Learn more ↗

GitHub Desktop

05 · NO TERMINAL NEEDED

A free app for commits, branches and pushes with buttons instead of commands.

TRY THISClone your repo with GitHub Desktop and make one commit.
Learn more ↗

Deploy with Vercel

06 · GO LIVE

Connect the repo to Vercel. Every push to main updates your live website automatically.

TRY THISImport your repo at vercel.com/new and click Deploy.
