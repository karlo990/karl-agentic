ACADEMY / 3D

Selected Blender skills

Blender is free, open-source 3D software. These are the first skills to learn, in the order we'd learn them.

PART 17 LESSONSFROM OUR INSTAGRAM SERIES

Move around the scene

01 · NAVIGATION

Orbit with the middle mouse button, pan with Shift + middle mouse, zoom with the scroll wheel. Number pad keys give front (1), side (3) and top (7) views.

TRY THISSpend five minutes orbiting the default cube until it feels natural.
Learn more ↗

Grab, rotate, scale

02 · TRANSFORM

Press G to move, R to rotate and S to scale. Type X, Y or Z after to lock to an axis.

TRY THISScale the cube to half size on Z only: S, Z, 0.5, Enter.
Learn more ↗

Edit mode modelling

03 · MODEL

Tab enters Edit Mode. Extrude with E, inset faces with I, add a loop cut with Ctrl+R and bevel edges with Ctrl+B.

TRY THISTurn a cube into a simple mug: inset the top face, then extrude it down.
Learn more ↗

Modifiers

04 · NON-DESTRUCTIVE

Subdivision Surface smooths a shape, Bevel rounds edges, Solidify adds thickness. You can change them any time without losing work.

TRY THISAdd a Subdivision Surface modifier with Ctrl+2 and right-click → Shade Smooth.
Learn more ↗

Materials

05 · LOOK

The Principled BSDF shader handles most materials. Base Color sets the colour, Roughness sets how glossy it is (low = shiny).

TRY THISMake glossy brand pink: Base Color #F0287A, Roughness 0.25.
Learn more ↗

Three-point lighting

06 · LIGHT

A bright key light at 45°, a softer fill light opposite, and a rim light behind the object to separate it from the background.

TRY THISLight your mug with three Area lights and compare it to a single light.
Learn more ↗

Render

07 · EXPORT

Cycles is slower but realistic; Eevee is fast and great for social posts. Press F12 to render, then Image → Save As to export a PNG.

TRY THISRender at 1080 × 1350 for an Instagram portrait post.
