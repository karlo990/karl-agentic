Best MCP servers

MCP (Model Context Protocol) is an open standard that lets AI apps such as Claude connect to your tools and data. An MCP server is the plug for one tool. These are the ones we reach for most.

FOR BUSINESS6 LESSONSFROM OUR INSTAGRAM SERIES

Google Drive

01 · DOCUMENTS

Lets the AI search and read your files, so it can answer questions from your own price lists, menus and policies.

GitHub

02 · CODE

Reads repos, opens issues and pull requests. This is how our coding agents ship work you can review.

Slack

03 · TEAM CHAT

Notion

04 · KNOWLEDGE BASE

Reads and updates pages and databases, which makes it a natural home for SOPs and client notes.

Stripe

05 · PAYMENTS

Creates payment links and checks invoices, so the agent can send a guest a deposit link mid-chat.

Playwright

06 · BROWSER

Lets an agent open real web pages, click and fill forms. Useful for testing your own site or checking competitor prices.
